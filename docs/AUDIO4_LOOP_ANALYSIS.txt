ALGORITHM AND RANKING
Native-rate float PCM from FFmpeg for refinement and audition; separate 11025-Hz
features use 2048-sample Hann FFT / 220-sample hop, 32 log-frequency bands,
positive flux, RMS, stereo balance, entropy-weighted pitch-class similarity.
Conservative body excludes 10% head/tail plus low-energy tail margins. This is
a heuristic and can miss authored sections; it is not semantic music analysis.
Tempo/phase from flux autocorrelation; confidence gates beat and 4-beat priors.
Meter/downbeats are NOT proven. Tempo can be half/double rate or drift.
Coarse half-second + beat grid, spectral prefilter, context comparison, then
24 diverse seeds refined +/-160ms and native stereo waveform/jump refinement.
Min span defaults to 25% of decoded duration (48-66s here); configurable per track.
Costs combine spectral, harmonic, loudness, stereo, rhythm, onset, beat/phrase
and waveform continuity; score 100/(1+cost) is an audition rank, NOT a quality %.
Compare hard/25/50/100/150/250ms linear overlaps using rendered roughness, jump,
energy dip, and a duration penalty. Human ears may choose a different fade.
Exact weights and limitations: scripts/audio4/README.txt. Each JSON records
parameters, algorithm hash, source hash, tool versions, metrics and variants.

METADATA PROPOSAL / TIMING CONTRACT
INI-style sections fit current prefs.txt key=value conventions and are easy for
C/C++ to parse. [pack] contains schema_version, id, timebase=decoded_pcm,
crossfade_mode=linear_overlap, enabled=false and unreviewed status.
[deck_variant] contains source SHA-256, rate, loop_start/end seconds and samples,
crossfade_ms, safe_resume_start/end and per-track status. Candidate A is a draft
example only, not a selection. Pack id supports future SS2/custom registries.
Integer sample indices should be canonical; reject inconsistent times, wrong
source/rate, invalid bounds, unsupported semantics and unapproved status.

Given musical start S and hard splice E, a fade of F uses loop_end=E+F.
Overlap tail [E,E+F) with head [S,S+F), then resume at S+F. This keeps the
period E-S for every fade option. Do not restart at S after the overlap.
Resume region [S,E-0.25s] is conservative/provisional, not guaranteed safe for
every mid-note seek. It is a region suggestion, not random-start behavior.
